# Le Cabinet des énigmes

Un jeu de logique en français, jouable directement dans un navigateur. Le joueur doit résoudre quatre énigmes, avec un score, un chronomètre et des indices pénalisants.

## Lancer le jeu

Ouvrir `index.html` dans un navigateur moderne. Aucun serveur, aucune installation et aucune dépendance ne sont nécessaires.

## Structure

- `index.html` : structure de l’interface ;
- `style.css` : thème visuel responsive ;
- `script.js` : énigmes, progression, score, indices et chronomètre.
